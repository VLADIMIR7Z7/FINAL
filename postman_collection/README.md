# Yatube API

API для социальной сети Yatube. Проект предоставляет возможности для создания постов, комментариев, подписок на авторов и просмотра групп.

## Технологии

- Python 3.9
- Django 3.2
- Django REST Framework
- JWT аутентификация
- SQLite
